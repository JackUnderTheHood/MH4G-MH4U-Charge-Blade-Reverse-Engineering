## 为什么不直接润色这份文件？

`current_state.md` 是研究现场日志，不是成稿。它按实验推进持续追加，包含：

- 当时仍待验证的假设；
- 失败和后来撤回的候选；
- 已被新证据修正的旧解释；
- 每次安装、读回、恢复和下一步操作；
- 为避免事故而写的临时停止条件。

直接改写它会破坏研究历史，也可能让后来读者无法判断某个结论在什么时候被推翻。因此它保持原样，只作为 Research Archive 使用。

公开阅读应从根目录 README 开始，再按需要阅读 Technical Analysis、Research History 和 Porting Notes。
